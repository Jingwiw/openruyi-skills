# Commit Templates

## Subject Format

`type(scope): summary`

## Recommended Types

- `feat`
- `fix`
- `refactor`
- `docs`
- `test`
- `chore`

## Body Template

```markdown
Why
- Explain the problem and why this change is needed.

What
- List key changes and affected boundaries.

Validation
- List executed checks and outcomes.
- State unverified areas explicitly.

Impact
- Note compatibility, migration, or risk.
- Note follow-up items if needed.
```

## Multi-Commit Plan Template

```markdown
1. type(scope): summary
   Why: ...
2. type(scope): summary
   Why: ...
```
