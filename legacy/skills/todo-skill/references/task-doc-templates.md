# Task And History Templates

## TASKS.md Template

```markdown
# TASKS

## P0

- [ ] Task title with specific done condition.
- [ ] Task title with specific done condition.

## P1

- [ ] Task title with specific done condition.

## P2

- [ ] Task title with specific done condition.
```

## ACTION_HISTORY.md Template

```markdown
# ACTION HISTORY

## YYYY-MM-DD

1. What changed.
2. Why it changed.
3. Which boundary was affected.
```

## Priority Rubric

- `P0`: correctness, release blocking, architecture boundary risk, or hard dependency for current milestone.
- `P1`: important capability extension with clear near-term value.
- `P2`: deferred optimization, cleanup, or exploratory work.

## Task Quality Checklist

- State the intended outcome, not only the activity.
- Include at least one verification condition.
- Keep scope small enough for one focused implementation pass.
