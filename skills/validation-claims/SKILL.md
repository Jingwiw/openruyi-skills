# 验证结论分级

每个结论绑定对象身份、具体检查和原始结果。分开描述语法、构建、安装、加载、实际操作和内核行为；不要用一层成功概括所有层。

使用有区别的状态：通过、失败、待执行、环境不可用、不适用。失败分类为候选问题、环境/仓库问题、原因未明；分类也需要证据。

- runner 超时与内部被测程序的退出码分别解释；日志缺少结尾时保留未确认状态。
- lint 相比基线减少但仍非零，应说“改善但未清零”；用户接受剩余问题不改变其失败状态。
- 不同工具结论冲突时，分别保留对象、命令和证据；原因未确认前不指定哪方是 bug。
- 变更后只重用仍匹配对象和条件的结果。旧 SHA 的成功不能直接替代新 SHA 的验收；树相同时可说明等价依据，不重写历史身份。
- 面向 PR 提炼重要测试、链接与影响验收的限制，不堆原始计数；完整事实保留在证据位置。

可仅审阅一段别人提供的总结；不足时列出缺失证据，而不是重启全部实验。
